# hpe-mini

Minimal ECU/PCB project scaffold for Hellen One + KiCad.

## Structure
- hardware/: KiCad project files and board assets
- docs/: design notes, pinout, bring-up checklists

## Getting Started
1. Open KiCad and create your board/schematic inside hardware/.
2. Commit changes with Git.
3. Publish to GitHub once authenticated with GitHub CLI.
